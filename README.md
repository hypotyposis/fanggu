# 访古

A personal field guide to historic architecture — collect places to visit, keep check-in notes, and explore line-drawn halls, pagodas and grottoes from Han stone gateways to contemporary reconstructions.

以细线描的笔意，记下走过与向往的古迹。收录二百处古迹：最初三十六处及补录的隰县小西天、应县净土寺、景宁时思寺、定襄洪福寺、五台延庆寺、长治观音堂、西安城墙、西安钟楼与鼓楼，共四十四处默认已到访，日期留空；另预置用户指定的六十五处心愿。此前扩充的九处与本批河南、河北、山西新增八十二处，共九十一处默认未到访，已有浏览器记录优先。心愿只从古迹库中选择，每处都有线稿；到访后可记录日期与笔记。以现有卢舍那大佛线稿为风格母版，其余古迹与首页斗拱参照实景照片或历史图像，由内置 imagegen 逐张重绘；统一线描质感与透明底，沿用各朝代原有配色，并以东汉赭石、北魏藕紫、南朝暖褐、北齐玫瑰紫、隋代青瓷、近现代灰银补充色板；年表覆盖东汉至今，现存重建建筑单独标明年代。

## 打开

代码仓库保存页面、逻辑、图版清单与来源记录。图片、生成原稿和参考照片暂留本地，由 `.gitignore` 排除，沿用现有 `assets/` 路径。新克隆需要从本地素材副本补齐 `assets/plates/`、`assets/colored/`、`assets/color-studies/v1/` 中的 PNG 及 `assets/longmen-vairocana.png` 后才能显示图版。

纯静态页面，任意静态服务器即可：

```bash
python3 -m http.server 8765
```

然后访问 `http://localhost:8765/`。`proof.html?view=grid` 查看全套线稿，`proof.html?fig=<id>` 单独放大某一张（id 见 `sites.js`）。`color-proof.html` 查看设色总览，`color-proof.html?id=<id>` 并排比较线稿与设色。`sources.html` 查看线稿照片来源、摄影署名与许可；设色对照页另列实际取色照片与校对记录。

## 使用图鉴

- 在“图鉴”中按到访状态、国家、朝代／时代、地区、省份／都道府县、建筑类型和名称／地点组合筛选；“从图鉴选心愿”打开未到访古迹，点击“加入心愿单”收藏。
- 地区按华北、东北、华东等大区组织，省份与地区联动。建筑类型按已收录主体归类：殿堂、古塔、楼阁、戏台、石窟石刻、石阙、城墙城防、彩塑雕塑、门坊、桥梁、经幢、陵墓、宅第民居、壁画、天文台、碑刻、宫苑；复合条目可归多类。筛选只影响图鉴，地图与年表仍放在开头。国家切换会联动地区、行政区及朝代／时代；日本使用独立时代分类与配色。
- 点击卡片图版或“细读”进入独立详情页，地图与年表也直接打开对应古迹。浏览器 Back 或左上角“返回前页”会恢复筛选、搜索词、已展开卡片与浏览位置；详情链接可独立打开和刷新，旧的古迹锚点链接仍可使用。首页仅保留地图、年表和图鉴，不再拼接全部正文。
- 在图鉴卡片或详情页向右拖动“访”字印章，整幅设色图随进度淡入。拉满并松手后记录今日到访，“亲见”印章落下、压实回弹，印记保留在图版上；中途松手会退回线稿。到访日期与笔记可在记录里编辑，记不清日期可以留空，也可改回想去。
- 未到访和心愿单使用原有朝代配色线稿；已到访使用参照现存实物颜色绘制的设色图。图鉴、年表与详情同步切换；设色图缺失或加载失败时自动回退线稿。切换图版不改变个人记录。
- 移出心愿单后，条目仍保留在未到访图鉴中。不再提供自由登记或无图版卡片。
- 行迹只列已到访的古迹。全部库内条目已附位置，打卡后落图。年表采用固定三轨总览，邻近年份聚合为数字圆点；点选朝代或圆点后，下方每页展示四张线稿卡片。鼠标悬停或键盘聚焦可预览古迹，读图说明默认收起；未知确切纪年的造像标为约略年代。年表所选时期、聚合组和页码随浏览器 Back 恢复。
- 记录保存在当前浏览器的 `localStorage`，键为 `fanggu.library.v1`。不跨设备自动同步；换浏览器、网址或端口也属于不同存储空间。
- “导出备份”下载 JSON；“导入备份”预览后合并，同一条记录采用备份中的资料，其余保留。备份包含状态、日期、笔记与保留的旧登记资料，图版由网站提供。版本 2 仍使用原存储键，兼容版本 1 备份。

旧版自由登记的同名、同地点心愿会自动关联正式古迹（包括“奉国寺 / 义县”）；关联后不重复恢复旧状态。无法确定的旧记录在“旧记录待关联”中保留，可手动选择库内条目。原名称、地点和笔记始终保存在备份中。

## 结构

- `draft.js` — 制图基元：檐口、垂脊、鸱吻、斗拱、柱廊、台基、悬山 / 歇山 / 庑殿屋顶
- `buildings.js` — 建筑合成器（殿、楼阁、木塔、砖塔、密檐塔、华塔、圆殿、戏台、石窟……）与 SVG 渲染、描画动画
- `sites.js` — 二百处的内容、年代、地点与绘图参数
- `plates.js` — 已生成图版的本地路径、尺寸和说明，覆盖原绘图入口
- `colored-plates.js` / `artwork.js` — 设色图清单与按到访状态选图、加载失败回退
- `color-proof.html` — 可搜索、按朝代筛选的设色总览及逐张对照
- `main.js` — 首页图版、地图与年表初始化
- `timeline.js` — 固定高度的年代总览、聚合点、朝代选择、图版翻页与历史状态恢复
- `detail.html` / `detail.js` — 独立古迹详情与个人记录展示
- `navigation.js` — 详情链接、旧锚点兼容与历史记录状态校验
- `journal.js` — 图鉴与详情页共用的心愿、打卡表单和本地记录动作
- `visit-slider.js` — 拖动设色、取消与保存边界、盖戳动效和到访印记
- `library.js` — 个人记录、校验、本地持久化与备份合并
- `catalog.js` — 地域、建筑类型与组合筛选规则
- `atlas.js` — 图鉴筛选、备份、记录联动与返回时的浏览状态恢复
- `tests/library.test.cjs` — 记录状态、备份恢复及存储失败验证
- `style.css` — 墨底、金线、朱砂的视觉系统
- `assets/plates/` — 页面实际使用的按朝代着色的透明底图版
- `assets/generated/` — imagegen 黑线白底原稿
- `assets/references/` — 风格母版与下载的建筑参考
- `assets/research/` — 每张图的来源、许可、最终提示词与生成记录
- `scripts/prepare-plates.mjs` — 按原有朝代色板着色、导出图版清单与来源页（需 Node.js、ImageMagick）

新增条目须先完成实景参考、imagegen 原稿和考据 JSON，再写入 `sites.js`。缺少图版或来源时，下面的构建会报错。

重建图版交付文件：

```bash
node scripts/prepare-plates.mjs
```

验证功能与图版：`node --test tests/*.test.cjs`。完整测试会读取本地图版及参考照片；新克隆须先补齐上述图片和考据 JSON 所列的参考文件。新增考据条目默认未到访。只有用户明确指定的已到访与心愿才在 `sites.js` 设置 `initialStatus: 'visited'` 或 `'wishlist'`；浏览器内后续修改会覆盖这一初始状态。

设色交付清单由 `node scripts/collect-colored-plates.mjs --require-complete` 汇总并检查。新增 197 张存于 `assets/colored/`，沿用的三张小样存于 `assets/color-studies/v1/`。每张新增图的实拍来源、取色观察、完整提示词、输入图像与逐图检查记录见 `assets/color-research/<id>.json`；[完整提示词清单](assets/color-research/prompts.json) 可用于复查。内置 imagegen 在原线稿构图上填色，不经过朝代色板转换；生成原件另存于各记录的 `generated_original` 路径。

## 说明

线稿为参照照片的艺术意写，非实测图；复杂斗拱、砖雕与瓦纹做了简化。原有条目的尺寸与年代沿用项目资料；新增条目的年代与形制已核对文物资料，回龙寺以宋金之际作约略定位。参考照片及历史图像的来源、署名、许可见 `sources.html`；卢舍那原图保持不变。

本批补充的延庆寺按山西五台县善文村金代大佛殿登记。三阙分别建卡，“后母阙”作为启母阙的搜索别名；东岳庙以飞云楼、后土祠以秋风楼为图版主体。黄花滩塔位于辽宁朝阳。繁峙三寺与福州双塔分别建卡。所有个人记录优先于新增默认状态。

江浙补遗新增23条心愿，浙江10条、江苏13条。虎丘云岩寺塔与二山门分条；图版均有实拍依据，局部对象明确写在图注。新昌大佛新增南朝暖褐配色；五代十国章节及年表分别标示五代与延续至北宋初年的十国。完整目录、提示词及参考来源见 [江浙图版记录](assets/research/jiangzhe-plates.md)。

河南、河北、山西补遗新增82处（27／25／30），总库达到200处。三省分别收录34／35／70处。新增条目默认未到访；既有心愿、打卡、笔记与备份逻辑保持。隋代新增青瓷色，北汉与北地五代遗存的年表标记置于北侧。新条目包括木构、石窟、塔幢、城防、桥梁、墓葬、民居与壁画，完整名单见 [三省补遗图版记录](assets/research/north200-plates.md)。
