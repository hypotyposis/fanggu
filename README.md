# 访古

开发入口：[AGENTS.md](AGENTS.md) · [开发指南](docs/development.md) · [图版维护](assets/README.md)

A personal field guide to historic architecture — collect places to visit, keep check-in notes, and explore line-drawn halls, pagodas and grottoes from Han stone gateways to contemporary reconstructions.

以细线描的笔意，记下走过与向往的古迹。收录二百零五处古迹：最初三十六处及补录的隰县小西天、应县净土寺、景宁时思寺、定襄洪福寺、五台延庆寺、长治观音堂、西安城墙、西安钟楼与鼓楼，共四十四处默认已到访，日期留空；另预置用户指定的六十五处心愿。此前扩充的九处与本批河南、河北、山西新增八十二处，加上济南灵岩寺辟支塔与本次河南四处补遗，共九十六处默认未到访，已有浏览器记录优先。心愿只从古迹库中选择，每处都有线稿；到访后可记录日期与笔记。以现有卢舍那大佛线稿为风格母版，其余古迹与首页斗拱参照实景照片或历史图像，由内置 imagegen 逐张重绘；统一线描质感与透明底，沿用各朝代原有配色，并以东汉赭石、北魏藕紫、南朝暖褐、北齐玫瑰紫、隋代青瓷、近现代灰银补充色板；年表覆盖东汉至今，现存重建建筑单独标明年代。

## 打开

代码仓库保存页面、逻辑、图版清单与来源记录。图片、生成原稿和参考照片暂留本地，由 `.gitignore` 排除。网页设色图使用 `assets/colored-transparent-avif/` 中的透明 AVIF Q85（4:4:4），透明线稿使用 `assets/plates/` 中的 PNG 及 `assets/longmen-vairocana.png`。新克隆需补齐这些运行图版；`assets/colored/` 与 `assets/color-studies/v1/` 中的原始 PNG 作为素材库完整保留，用于重新转码及按需查看原图。新增或重绘默认由内置 imagegen 输出纯白底 PNG，再由本地脚本去底；原件保留，线稿按灰度生成透明笔画，设色仅去除外部白底并清理白边，最后输出透明 PNG／AVIF，无需 API Key。

纯静态页面，任意静态服务器即可：

```bash
python3 -m http.server 8765
```

然后访问 `http://localhost:8765/`。`proof.html?view=grid` 查看全套线稿，`proof.html?fig=<id>` 单独放大某一张（id 见 `sites.js`）。`color-proof.html` 查看设色总览，`color-proof.html?id=<id>` 并排比较原设色或线稿与透明设色，可切换深浅及棋盘格背景，并用 ← → 逐张审图。本轮 200 张透明设色已由用户确认通过，并用于正式页面。`sources.html` 查看线稿照片来源、摄影署名与许可；设色对照页另列实际取色照片与校对记录。

## 使用图鉴

- 在“图鉴”中按到访状态、国家、朝代／时代、地区、省份／都道府县、建筑类型和名称／地点组合筛选；“从图鉴选心愿”打开未到访古迹，点击“加入心愿单”收藏。
- 地区按华北、东北、华东等大区组织，省份与地区联动。建筑类型按已收录主体归类：殿堂、古塔、楼阁、戏台、石窟石刻、石阙、城墙城防、彩塑雕塑、门坊、桥梁、经幢、陵墓、宅第民居、壁画、天文台、碑刻、宫苑；复合条目可归多类。筛选只影响图鉴，地图与年表仍放在开头。国家切换会联动地区、行政区及朝代／时代；日本使用独立时代分类与配色。
- 点击卡片图版或“细读”进入独立详情页，地图与年表也直接打开对应古迹。浏览器 Back 或左上角“返回前页”会恢复筛选、搜索词、已展开卡片与浏览位置；详情链接可独立打开和刷新，旧的古迹锚点链接仍可使用。首页仅保留地图、年表和图鉴，不再拼接全部正文。
- 在图鉴卡片或详情页向右拖动“访”字印章，整幅设色图随进度淡入。拉满并松手后记录今日到访，“亲见”印章落下、压实回弹，印记保留在图版上；中途松手会退回线稿。到访日期与笔记可在记录里编辑，记不清日期可以留空，也可改回想去。
- 未到访和心愿单使用原有朝代配色线稿；已到访使用参照现存实物颜色绘制的设色图。图鉴、年表与详情同步切换；设色图缺失或加载失败时自动回退线稿。切换图版不改变个人记录。
- 在图鉴卡片或详情页点击“写短评 / 打分”，为每处古迹保存一条我的评价：1–5 星、最多 500 字符短评，两项都可选填。可修改或清除；取消和 Escape 不保存。评价与到访笔记分开，也不会自动标记已到访。当前为单机个人评价，仅保存在当前浏览器。
- 移出心愿单后，条目仍保留在未到访图鉴中。不再提供自由登记或无图版卡片。
- 到访地图以整栏大图标记已到访地点，点选地点可细读古迹。全部库内条目已附位置，打卡后落图；地点之间不连线。年表采用固定三轨总览，邻近年份聚合为数字圆点；点选朝代或圆点后，下方每页展示四张线稿卡片。鼠标悬停或键盘聚焦可预览古迹，读图说明默认收起；未知确切纪年的造像标为约略年代。年表所选时期、聚合组和页码随浏览器 Back 恢复。
- 记录保存在当前浏览器的 `localStorage`，键为 `fanggu.library.v1`。不跨设备自动同步；换浏览器、网址或端口也属于不同存储空间。
- “导出备份”下载 JSON；“导入备份”预览后合并，同一条记录或评价采用备份中的资料，其余保留。备份包含状态、日期、笔记、评分、短评与保留的旧登记资料，图版由网站提供。版本 3 仍使用原存储键，兼容版本 1、2 备份；旧备份不覆盖当前评价。

旧版自由登记的同名、同地点心愿会自动关联正式古迹（包括“奉国寺 / 义县”）；关联后不重复恢复旧状态。无法确定的旧记录在“旧记录待关联”中保留，可手动选择库内条目。原名称、地点和笔记始终保存在备份中。

## 说明

线稿为参照照片的艺术意写，非实测图；复杂斗拱、砖雕与瓦纹做了简化。原有条目的尺寸与年代沿用项目资料；新增条目的年代与形制已核对文物资料，回龙寺以宋金之际作约略定位。参考照片及历史图像的来源、署名、许可见 `sources.html`；卢舍那原图保持不变。

本批补充的延庆寺按山西五台县善文村金代大佛殿登记。三阙分别建卡，“后母阙”作为启母阙的搜索别名；东岳庙以飞云楼、后土祠以秋风楼为图版主体。黄花滩塔位于辽宁朝阳。繁峙三寺与福州双塔分别建卡。所有个人记录优先于新增默认状态。

江浙补遗新增23条心愿，浙江10条、江苏13条。虎丘云岩寺塔与二山门分条；图版均有实拍依据，局部对象明确写在图注。新昌大佛新增南朝暖褐配色；五代十国章节及年表分别标示五代与延续至北宋初年的十国。完整目录、提示词及参考来源见 [江浙图版记录](assets/research/jiangzhe-plates.md)。

河南、河北、山西补遗新增82处（27／25／30），总库达到200处。三省分别收录34／35／70处。新增条目默认未到访；既有心愿、打卡、笔记与备份逻辑保持。隋代新增青瓷色，北汉与北地五代遗存的年表标记置于北侧。新条目包括木构、石窟、塔幢、城防、桥梁、墓葬、民居与壁画，完整名单见 [三省补遗图版记录](assets/research/north200-plates.md)。

河南续补妙乐寺塔、法王寺塔、北宋皇陵与浚县碧霞宫，河南收录量增至38处，总库205处。四处均默认未到访，补齐实拍来源、线稿与设色透明交付图；法王寺塔取上部局部，宋陵取永昭陵原存文官石像，碧霞宫取前部拜殿。新增图版待用户审阅，考据、真实提示词与生成记录见 [河南续补记录](assets/research/henan-additions-2026-09-18.md)。
