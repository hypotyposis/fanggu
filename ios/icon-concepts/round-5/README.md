# 莲花状辽代斗栱图标草案

以应县木塔和独乐寺等辽代木构檐下的多层斗栱为视觉参考，提炼斗块、层层外展的拱臂和檐枋。这里的“莲花”指斗栱成簇、外展如花的整体姿态；草案不是对某一朵实物斗栱的测绘复原。

参考资料：

- [人民网：应县木塔斗栱如簇簇莲花](https://art.people.com.cn/n1/2019/0318/c226026-30981078.html)
- [新华网：应县木塔转角斗栱如盛开的莲花](https://sg.xinhuanet.com/2013-02/20/c_124366709.htm)
- [澎湃新闻：独乐寺观音阁檐下斗栱照片](https://www.thepaper.cn/newsDetail_forward_22859482)

`01`–`05` 是可编辑 SVG 探索；`06`–`08` 是基于上述实物形态描述生成的位图概念稿，未把实物照片作为输入，也不能当作某件辽构的测绘复原。对照图用于桌面尺寸评估；均未替换正式 App 图标。
