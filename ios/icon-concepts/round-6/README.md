# 转角斗栱简化方案

从用户选定的 `../round-5/06-ornate-corner-raster.png` 提取三个元素：V 形檐角、中心斗块、成对外展的拱臂。
实物参照与“莲花状”用语来源见 [上一轮资料](../round-5/README.md)。

- `04`、`05`、`06`：沿原图生成的平面化概念；`06` 将拱臂收为三层，是 `comparison-four-simplifications.png` 中的 C。
- `01`–`03`：进一步压缩成三层拱臂的可编辑 SVG。
- `comparison-four-simplifications.png`：A–D 四档简化程度在大图和 76 px 下的对照；`01` 是其中的 D。

用户认可 C 的抽象程度后，`07-selected-vector.svg` 被制作成正式可编辑图标，并同步到 `../../AppIcon.svg`；对应 PNG 由该 SVG 导出到 App 的资产目录。它是设计标志，不作为历史构造图使用。

此方案随后被[用户选定的原图版本](../round-7/README.md)取代。
