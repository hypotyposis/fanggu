许国石坊的营建年与四面八柱形制依据黄山市人民政府资料。振风塔采用人民日报等资料的通行纪年，同时保留安庆地方文献提出的1572年建成说，界面标为“约1570”，不把排序点写成无争议的精确断代。花戏楼区分1656年关帝庙始建与1676年戏台增建，不用山门照片替代院内戏台。

许国石坊及花戏楼采用 Wikimedia Commons 实拍，摄影署名与 CC BY-SA 4.0 许可列在逐图 JSON 和来源页；由摄影转译为简化插图，铭文省略。振风塔主参考为携程用户“想要去环游全世界”2022年游记的近正面及航拍照片，未声明开放许可，版权归摄影作者，仅作为研究和生成参考；2008年 Angus Cepka 的 CC BY-SA 2.5 旧照用于补核砖石构件。主参考不直接作为网站图版发布。坐标来自 Commons 分类页，供城市或县城聚合展示参考，非测绘成果。

使用内置 imagegen，线稿输入卢舍那风格母版及实拍，设色输入实际线稿、材料照片与佛光寺画法样本。实际首轮及修正提示词见 [本次提示词集合](anhui-prompts.json)，每张的输入与工具原件路径亦保存在逐图记录。许国石坊首轮因透明光晕弃用；振风塔首轮因塔檐过于木构楼阁化、底层轮廓不实弃用；候选原件仍保存在本地，未作为网页交付。

最终线稿与设色均为不透明白底 PNG 原件，分别保存在 `assets/generated/<id>.png` 与 `assets/colored/<id>.png`。逐图 `background_preparation` 以实际 SHA-256 绑定原件；线稿按灰度生成 alpha 后统一着明清青蓝色，设色仅移除外缘连通白底和实际查看的透空种子，保留浅色砖石与戏台暗部。透明 PNG 在 `assets/plates/` 与 `assets/colored-transparent/`，网页设色使用 `assets/colored-transparent-avif/` 的 AVIF Q85、4:4:4 副本。流程与命令见 [开发指南](../../docs/development.md)。

已实际查看原件并核对主体、层数或开间、完整构图、材料色分布、文字和背景；由照片转换为近立面视角、装饰与券洞经艺术简化，不宣称像素配准、实测准确或文保色彩复原。生成记录的 `complete` 表示生产记录齐备，透明交付清单的用户视觉验收仍为 `pending_user`。

复核入口：`proof.html?fig=<id>`、`color-proof.html?id=<id>`、`detail.html?id=<id>` 与 `sources.html#<id>`。图片、参考照片和原件需要一并补齐本地素材；只有 Git 清单不会自动部署图片。
