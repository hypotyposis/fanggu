白底原件完整保留于 `assets/generated/`、`assets/colored/`，来源哈希写入 `background_preparation`。交付路径为 `assets/plates/`、`assets/colored-transparent/`、`assets/colored-transparent-avif/`。照片、PDF、图片和素材包受 Git 忽略，存在于当前工作区，不能将 Git 中的路径记录当作图片随仓库交付。
